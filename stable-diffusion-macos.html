ALICE

Generate images locally.

ALICE is a Stable Diffusion service for macOS and Linux with an OpenAI-compatible API. Text-to-image, image-to-image, and unlimited generation on your own hardware.

Download ALICE Read the Docs

Free and open source. macOS (MPS) and Linux (CUDA, ROCm, Vulkan). Deploy standalone or via Docker.

Your GPU, your data, your creations.

Text-to-image and image-to-image

Generate images from text prompts or transform existing images. FastAPI service with OpenAI-compatible API and web interface.

Download any model

CivitAI, HuggingFace, or local checkpoints. SDXL, SD 1.5, GGUF, and custom fine-tuned models all supported.

Multi-GPU support

NVIDIA CUDA, AMD Vulkan/ROCm, Apple MPS, and CPU fallback. PyTorch and stable-diffusion.cpp backends.

SAM integration

Generate images directly from SAM conversations. ALICE handles the heavy lifting.

Docker and systemd deployment

Deploy via Docker, systemd service, or launchd daemon. Self-update system keeps ALICE current automatically.

Web interface and REST API

Browse models, configure parameters, manage gallery with pagination. OpenAI-compatible API for integration with any tool.

Complete control over generation.

Adjust steps, guidance scale, samplers, and schedulers. Use negative prompts, LoRA models, and embeddings.

Full Stable Diffusion capabilities without compromise.

Generation Controls

Privacy by design.

All image generation happens on your hardware. No cloud services, no data collection, no usage tracking.

Your prompts and generated images stay on your machine. Run on macOS or Linux - your GPU, your data, your creations.

Local Processing

Batch generation and automation.

Generate multiple images with varying seeds. Queue batches for overnight generation. Automate workflows via REST API.

Perfect for artists, designers, and creative professionals.
