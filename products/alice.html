Generation studio

Text-to-image and image-to-image with full parameter control. LoRA models, negative prompts, multiple schedulers, seed control, and resolution presets.

Private gallery

Masonry grid gallery with per-image privacy controls. Optional time-limited public sharing. Regenerate from any image, view metadata, batch manage your collection.

Model marketplace

Browse, search, and download models from CivitAI and HuggingFace directly in the UI. SDXL, SD 1.5, FLUX, GGUF, and custom fine-tunes all supported.

Real-time dashboard

GPU memory, system metrics, generation history, and quick actions. Monitor everything from a single view.

Multi-GPU support

NVIDIA CUDA, AMD Vulkan/ROCm, Apple MPS, and CPU fallback. Dual backend architecture: PyTorch for full diffusers pipeline support, and stable-diffusion.cpp with Vulkan for universal GPU acceleration without vendor drivers.

Admin and authentication

User management, API key generation, role-based access. Deploy for yourself or share with your team.

Steam Deck ready

Dedicated SteamOS installer with user-level systemd service. Run Stable Diffusion on your Steam Deck's AMD GPU via ROCm or Vulkan - no desktop Linux required.

Docker deployment

Pre-built containers for CPU, CUDA, and ROCm on GitHub Container Registry. One command to run: docker compose --profile cuda up -d.
