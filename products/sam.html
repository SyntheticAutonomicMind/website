Import documents, link conversations via Shared Topics, and search by meaning. Build knowledge that grows with your projects.

Autonomous agents

Launch agents that work independently. Up to 300 iterations per task. Transparent reasoning at every step.

Your data stays local

Run everything offline with local MLX/GGUF models. Only connect to cloud providers when you choose.

Multi-provider support

OpenAI, GitHub Copilot, Google Gemini, DeepSeek, MiniMax, OpenRouter, MLX, and llama.cpp. Mix and match cloud and local models across all tools.

Access from any device

SAM-Web brings your assistant to any device on your network - iPad, iPhone, Android, or any browser. Full chat interface with streaming, tool execution, and image and audio generation.

macOS integration

Calendar, Contacts, Notes, Spotlight, and Weather - SAM works with the tools already on your Mac. Create events, look up contacts, search notes, all from the chat.

Track usage and costs

Per-conversation cost tracking shows exactly what you spend with cloud providers. Status bar displays real-time connection and usage info.

Terminal commands and file operations.

SAM executes shell commands, reads and writes files, and orchestrates complex workflows. Built-in tool system with safety validation.
