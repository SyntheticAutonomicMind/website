Privacy Controls

Manage image privacy and sharing

Default Privacy

All generated images are private by default. Only you can access them.

Making Images Public

Share images with time-limited public links:

  1. Select image in gallery
  2. Click "Make Public"
  3. Set expiration (1-168 hours)
  4. Share the generated URL

Privacy States

  • Private: Only accessible to owner
  • Public: Accessible via public URL
  • Expired: Public link no longer works

Access Control

Image access is controlled by:

  • API authentication (if enabled)
  • Public URL tokens
  • Expiration timestamps

Batch Privacy Changes

Update privacy for multiple images:

  1. Select images in gallery
  2. Choose "Change Privacy"
  3. Apply new settings

Best Practices

  • Use short expiration for sensitive images
  • Regularly review public images
  • Revoke public access when no longer needed
  • Use authentication for production deployments
