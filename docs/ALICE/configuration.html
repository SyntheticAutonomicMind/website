Configuration

ALICE configuration options

Configuration File

ALICE uses config.yaml for all settings located in the installation directory.

Server Settings

  • host - Bind address (default: 0.0.0.0)
  • port - HTTP port (default: 8080)
  • api_key - API key for authentication (default: none)
  • require_auth - Require API key for all requests (default: false)
  • registration_mode - User registration mode (default: disabled)
  • session_timeout_seconds - Session timeout (default: 900)
  • block_nsfw - Block NSFW content (default: true)

Model Settings

  • directory - Model storage path (default: ./models)
  • auto_unload_timeout - Seconds before unloading idle models (default: 0, currently ignored)

Generation Defaults

  • steps - Default inference steps (default: 25)
  • guidance_scale - Default CFG scale (default: 7.5)
  • scheduler - Default scheduler (default: dpm++_sde_karras)
  • width/height - Default dimensions (default: 512x512)
  • max_cached_models - Models to keep in GPU memory (default: 2)

Environment Variables

Override settings with environment variables for deployment flexibility.
