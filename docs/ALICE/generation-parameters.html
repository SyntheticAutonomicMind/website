Generation Parameters

Understanding image generation settings

Core Parameters

Steps (Inference Steps)

Number of denoising steps. More steps = better quality but slower.

  • Range: 1-150
  • Recommended: 20-30 for most models
  • Turbo models: 1-4 steps

Guidance Scale (CFG)

How closely to follow the prompt. Higher = more literal interpretation.

  • Range: 0.0-20.0
  • Recommended: 7-10
  • Turbo models: 0.0

Resolution

Image dimensions (must be multiples of 8).

  • SD 1.5: 512x512 native
  • SDXL: 1024x1024 native
  • FLUX: Flexible resolutions

Advanced Parameters

Scheduler

Determines how noise is removed during generation.

  • Best quality: DPM++ 2M Karras
  • Fastest: Euler Ancestral
  • Most accurate: DDIM

Seed

Random seed for reproducibility. Same seed + params = same image.

Negative Prompt

What to avoid in generation. Common negatives:

  • ugly, blurry, low quality
  • distorted, deformed
  • watermark, text
