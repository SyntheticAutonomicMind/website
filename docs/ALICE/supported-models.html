Documentation/Supported Models

Supported Models

Compatible Stable Diffusion model types

Model Types

SD 1.5 Models

Native Resolution: 512x512

Fast generation, good quality, widely available.

  • Original Stable Diffusion 1.5
  • Community fine-tunes
  • Specialized models (anime, photorealistic, etc.)

SDXL Models

Native Resolution: 1024x1024

Higher quality, better detail, more VRAM required.

  • SDXL Base 1.0
  • SDXL Turbo (1-4 steps)
  • SDXL fine-tunes

FLUX Models

Resolution: Flexible

Latest generation, excellent quality, experimental support.

Model Formats

Format Extension Recommended
Safetensors .safetensors Yes
PyTorch .pt, .pth, .bin No
Diffusers (directory) Yes

LoRA Support

ALICE supports LoRA (Low-Rank Adaptation) models:

  • Apply multiple LoRAs per generation
  • Control LoRA strength (0.0-1.0)
  • Compatible with all base models

Turbo Models

Optimized for speed (1-4 steps):

  • SD Turbo
  • SDXL Turbo
  • Use guidance_scale: 0.0
