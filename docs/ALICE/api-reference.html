Documentation/API Reference

API Reference

OpenAI-compatible API for image generation, audio generation, model management, authentication, and gallery operations

Authentication

All API endpoints accept an API key via the Authorization header:

Authorization: Bearer YOUR_API_KEY

Some endpoints require additional authentication for admin operations. See Authentication for details.

Image Generation

Endpoint: POST /v1/chat/completions

The chat completions endpoint accepts messages with image generation requests.

Request Format

{
  "model": "sdxl",
  "messages": [
    {"role": "user", "content": "A serene mountain landscape at sunset"}
  ],
  "samConfig": {
    "steps": 30,
    "guidance_scale": 7.5,
    "width": 1024,
    "height": 1024,
    "negative_prompt": "low quality, blurry",
    "seed": 12345,
    "scheduler": "dpm++_sde_karras"
  }
}

Response Format

Returns JSON with image URLs in the choices array.

Generation Defaults

Endpoint: GET /v1/generation/defaults

Returns the default generation parameters for the configured models.

Models API

List Models

Endpoint: GET /v1/models

Returns a list of all available image and audio models.

List Cached Models

Endpoint: GET /v1/models/cached

Returns models currently loaded in GPU memory.

Model Info

Endpoint: GET /v1/models/{model_id}/info

Returns detailed information about a specific model.

Evict Model

Endpoint: POST /v1/models/{model_id}/evict

Evicts a model from GPU cache to free memory.

Refresh Models

Endpoint: POST /v1/models/refresh

Rescans the model directory and updates the model list.

List LoRAs

Endpoint: GET /v1/loras

Returns all LoRA adapters available.

List Audio Models

Endpoint: GET /v1/models/audio

Returns all installed audio generation models.

Endpoint: GET /v1/models/download/status

Endpoint: DELETE /v1/models/download/{task_id}

Model Cache

Endpoint: GET /v1/models/cache/status

Authentication API

Generate API Key

Endpoint: POST /v1/auth/keys/generate

Generate a new API key.

List API Keys

Endpoint: GET /v1/auth/keys

Returns all API keys.

Delete API Key

Endpoint: DELETE /v1/auth/keys/{key_id}

Delete an API key.

Endpoint: POST /v1/auth/keys/{key_id}/revoke

Create Session

Create a web authentication session.

Endpoint: GET /v1/auth/sessions

Returns all active sessions.

Delete Session

Endpoint: DELETE /v1/auth/sessions/{session_id}

Endpoint: GET /v1/auth/me

Returns information about the current authenticated user.

Authentication Stats

Endpoint: GET /v1/auth/stats

Returns authentication statistics.

Bootstrap Registration

Endpoint: POST /v1/auth/bootstrap

Bootstrap the first admin user on a fresh installation.

Registration Mode

Endpoint: GET /v1/auth/registration-mode

Check if registration mode is enabled.

Register User

Endpoint: POST /v1/auth/register

Register a new user (requires registration mode).

Invitations

Endpoints:

  • POST /v1/auth/invites - Create an invitation
  • GET /v1/auth/invites - List invitations
  • DELETE /v1/auth/invites/{code} - Delete an invitation

Pending Registrations

Endpoints:

  • GET /v1/auth/pending - List pending registrations
  • POST /v1/auth/pending/{reg_id}/approve - Approve a pending registration
  • POST /v1/auth/pending/{reg_id}/reject - Reject a pending registration
  • DELETE /v1/auth/pending/{reg_id} - Delete a pending registration

SAM Config Parameters

All fields are optional - server uses defaults if omitted.

Field Type Description
steps int (1-150) Inference steps
guidance_scale float (0.0-20.0) CFG scale
width int (64-2048) Image width
height int (64-2048) Image height
negative_prompt string Negative prompt
seed int Random seed
scheduler string Scheduler name

Valid Schedulers

  • euler, euler_ancestral
  • dpm++_sde_karras (default), dpm++_2m_karras
  • ddim, pndm, lms, heun
