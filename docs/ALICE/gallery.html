Gallery

Manage and organize generated images

Gallery Features

The ALICE gallery provides complete image management:

  • Browse all generated images
  • Search by prompt or metadata
  • Batch operations (delete, privacy changes)
  • View generation parameters
  • Re-generate with same settings

Organization

Images are stored with full metadata including:

  • Original prompt and negative prompt
  • Model and scheduler used
  • Seed and all parameters
  • Generation timestamp
  • Privacy status

Search & Filter

Find images quickly with:

  • Text search in prompts
  • Filter by model
  • Filter by date range
  • Filter by privacy status

Batch Operations

Select multiple images to:

  • Delete in bulk
  • Change privacy settings
  • Export metadata
