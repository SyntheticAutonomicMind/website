Artificial Latent Image Composition Engine - Local Stable Diffusion server for macOS and Linux

What is ALICE?

ALICE is a local image generation server that runs Stable Diffusion on your hardware. It provides an OpenAI-compatible HTTP API, a web-based generation studio, a private gallery, and a model marketplace. No subscription, no cloud upload, no per-image cost. Your prompts and images never leave your machine.

Why Choose ALICE?

  • Runs locally - All generation happens on your GPU. No cloud dependency.
  • Full studio - Web interface with text-to-image, image-to-image, LoRA support, and parameter control.
  • Model marketplace - Browse and download models from CivitAI and HuggingFace directly in the UI.
  • Privacy-first - Private gallery with per-image sharing controls. Time-limited public links.
  • Multi-GPU - NVIDIA CUDA, AMD Vulkan/ROCm, Apple MPS, CPU fallback, and Steam Deck.
  • Integrates with SAM - Generate images from SAM conversations via the API.
