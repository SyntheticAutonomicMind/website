Slash Commands Reference

Complete reference for CLIO's slash commands

Command Overview

Slash commands give you direct control of CLIO without going through the AI. All commands start with / (a bare ? is shorthand for /help). Type /help in the chat for the live list, or /help <command> for details on one command.

Basics

Command Description
/help aliases: h, ? Display the command list; /help git shows command-specific help
/clear aliases: cls Clear and repaint the screen
/reset Reset the terminal and kill stale processes
/debug Toggle debug mode
/color Toggle color output
/exit aliases: quit, q Exit the chat
/init Initialize CLIO for this project (AI-assisted custom instructions)
/multi-line aliases: multiline, multi, ml Open an editor for multi-line input
/shell aliases: sh Open an interactive shell
/exec <cmd> Run a shell command

API & Configuration

Configure AI providers, models, and all CLIO settings.

Command Description
/api Configure the AI provider, model, and login (/api login, /api logout, /api models, /api set)
/model Quick-switch the active AI model
/login, /logout Shorthand for /api login and /api logout
/models Shorthand for /api models
/config Manage configuration settings (/config show, /config set KEY VALUE)
/loglevel Get or set the log level
/style, /theme, /preview Manage color schemes and output themes, and preview before applying
/billing aliases: bill, usage Show API usage statistics

Sessions & Context

Command Description
/session List, switch, name, export, prune, and manage sessions
/switch Shorthand for /session switch
/context aliases: ctx Manage context files attached to the session

File & Git

Command Description
/file File operations: read, edit, write, list
/read, /edit Shorthands for /file read <path> and /file edit <path>
/git Git operations: status, diff, commit, log, branch, stash, push, pull, merge, blame, worktree
/status, /diff, /commit, /gitlog Shorthands for the matching /git subcommands
/undo Revert AI changes from the last turn

Multi-Agent & Remote

Command Description
/subagent aliases: agent Spawn and manage sub-agents
/mux aliases: multiplexer Control terminal multiplexer panes
/device aliases: dev List and manage registered devices
/group List and manage device groups for parallel remote execution

Skills, Prompts & Specs

Command Description

Memory & Profile
