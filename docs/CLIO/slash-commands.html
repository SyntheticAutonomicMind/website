Slash Commands Reference

Complete reference for CLIO's slash commands

Command Overview

Slash commands provide direct access to CLIO features and configuration. All commands start with : or /.

General Commands

Command Description
/help Show available commands
/clear Clear the screen
/exit or /quit Exit CLIO
/multiline or /ml Open editor for multi-line prompts

API & Configuration

Configure AI providers, models, and all CLIO settings.

Command Description
/api login Authenticate with GitHub Copilot
/api set provider NAME Set AI provider (openai, anthropic, deepseek, google, etc.)
/api set key VALUE Set API key
/api set model NAME Set model (run /api models to list available)
/api models List available models for current provider
/api providers List all configured providers
/api logout Clear stored API credentials
/config show Display current configuration
/config save Save configuration to disk
/config set KEY VALUE Set a configuration value

Session Management

Command Description
/session list List all saved sessions
/session switch ID Switch to a different session
/session delete ID Delete a session
/session export ID Export session to file
/session new [TITLE] Create a new session

Memory Commands

CLIO persists key-value memory and long-term memory across sessions.

Command Description
/memory store KEY VALUE Store key-value pair
/memory get KEY Retrieve stored value
/memory list List all memory keys
/memory search QUERY Search memory
/memory delete KEY Delete memory entry
/memory ltm View long-term memory entries
/memory prune Clean up old memory entries

Todo Management

Command Description
/todo list Show current todo list
/todo add TITLE Add new todo
/todo done ID Mark todo as complete
/todo delete ID Delete a todo
/todo clear Clear completed todos

Development Commands

Code understanding, file operations, and project management.

Command Description
/file read PATH Read a file from the working directory
/file edit PATH Edit a file interactively
/git status Show git status
/git diff [FILE] Show git diff
/git log [N] Show recent commits
/git commit MESSAGE Stage and commit changes
/git push [REMOTE] [BRANCH] Push changes
/git pull [REMOTE] [BRANCH] Pull changes
/log [N] Show conversation log
/context Show current context stats and length
/mux Multiplexer pane management
/stats Show token, cost, and conversation statistics
/project init Initialize a new project
/project design Create a product requirements document
/spec List and run spec tests
/skills List and manage skills
/prompt List and set prompts
/profile Show or set user profile
/billing Show API usage and billing info
/update Check for and apply CLIO updates

AI Commands

Command Description
/ai explain Explain selected code
/ai review Review code for issues
/ai test Generate tests for code

Customization

Command Description
/theme Change color theme
/debug Toggle debug mode
/verbose Toggle verbose output
