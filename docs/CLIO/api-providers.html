AI Providers

Configure and use different AI providers with CLIO

Supported Providers

CLIO supports multiple AI providers for maximum flexibility:

GitHub Copilot (Recommended)

Models: GPT-4o, Claude 3.5 Sonnet, o1-preview, o1-mini

Cost: $10/month (Individual) or $19/month (Business)

Setup:

: /api login
# Follow browser prompts to authorize

OpenAI

Models: GPT-4o, GPT-4 Turbo, GPT-3.5 Turbo, o1 models

Cost: Pay-as-you-go

Setup:

: /api set provider openai
: /api set key YOUR_OPENAI_API_KEY
: /api set model gpt-4o

Anthropic Claude

Models: Claude 3.5 Sonnet, Claude 3 Opus, Claude 3 Haiku

Setup:

: /api set provider anthropic
: /api set key YOUR_ANTHROPIC_API_KEY
: /api set model claude-3-5-sonnet-20241022

DeepSeek

Models: DeepSeek Coder, DeepSeek Chat

Cost: Very cost-effective for coding tasks

Setup:

: /api set provider deepseek
: /api set key YOUR_DEEPSEEK_API_KEY
: /api set model deepseek-coder

OpenRouter

Models: Access to 200+ models from multiple providers

Setup:

: /api set provider openrouter
: /api set key YOUR_OPENROUTER_API_KEY
: /api set model anthropic/claude-3.5-sonnet

llama.cpp (Local)

Models: Any GGUF model

Cost: Free (runs locally)

Setup:

# Start llama.cpp server
./llama-server -m model.gguf --port 8080

# Configure CLIO
: /api set provider llamacpp
: /api set endpoint http://localhost:8080
: /api set model local-model

SAM (Local)

Models: MLX and GGUF models via SAM

Cost: Free (runs locally)

Setup:

: /api set provider sam
: /api set endpoint http://localhost:8000
: /api set model sam-default

Configuration Commands

# Set provider
: /api set provider 

# Set API key
: /api set key 

# Set model
: /api set model 

# List available models for current provider
: /api models

# Save configuration
: /config save

# Show current configuration
: /config show

Model Selection Tips

  • For coding: GPT-4o, Claude 3.5 Sonnet, DeepSeek Coder
  • For reasoning: o1-preview, o1-mini
  • For speed: GPT-3.5 Turbo, Claude 3 Haiku
  • For privacy: llama.cpp or SAM (local models)
  • For cost: DeepSeek, GPT-3.5 Turbo
