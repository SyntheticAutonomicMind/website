AI Providers

Configure and use different AI providers with CLIO. Models change frequently — use /api models inside CLIO to see current availability.

Configuration Commands

All provider configuration is done with the /api command inside CLIO:

# See all providers
/api providers

# Get details for a specific provider
/api providers github_copilot

# Switch provider
/api set provider 

# Set API key
/api set key 

# Set model
/api set model 

# List available models for your provider
/api models

# View current configuration
/api show

# Save configuration
/config save

Model Selection Tips

  • For coding: Latest GPT-4, Claude, or DeepSeek Coder models
  • For reasoning: o1 or comparable reasoning models
  • For speed: Faster, smaller models
  • For privacy: llama.cpp or SAM (local models)
  • For cost: DeepSeek or smaller cloud models

Models change frequently. After configuring your provider, use /api models to see the current list of available models.
