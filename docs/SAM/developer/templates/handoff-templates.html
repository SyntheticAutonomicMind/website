Handoff Templates

Templates for session handoff documents used in The Unbroken Method.

These documents ensure perfect context transfer between sessions, whether you're handing off to yourself tomorrow or to a teammate.

With CLIO: Session persistence and long-term memory handle most context preservation automatically. Handoff documents are still created for explicit session transitions, but the manual overhead is significantly reduced. CLIO's LTM system captures discoveries, solutions, and patterns across all sessions without manual documentation.

Overview

When a session must end, create these documents in a timestamped handoff directory:

Document Purpose Required?
CONTINUATION_PROMPT.md Complete standalone context for next session Mandatory
AGENT_PLAN.md Remaining work breakdown with investigation steps Mandatory
NOTES.md Technical notes, discoveries, design decisions Optional

Some projects may benefit from additional documents like FEATURES.md (user-facing changes) or CHANGELOG.md (release notes). Templates for these are included below under Project-Specific Additions.

CRITICAL PREREQUISITE: Before creating handoff documents, ensure ALL technical documentation is up-to-date: - Subsystem docs if you modified a component - Flow diagrams if you changed data flows - Specifications if you completed a feature

Rule: Documentation is NOT optional. Code without docs is incomplete work.

Usage Tips

When to Create Handoffs

  • Token limits approaching - Create full handoff before context is lost
  • Work phase complete - Document what was accomplished
  • Switching focus - Preserve context for current work
  • End of day - Ensure tomorrow picks up smoothly
  • Team handoff - Transferring work to another person

Quality Checklist

Before finalizing handoff documents:

  • [ ] CONTINUATION_PROMPT is completely standalone
  • [ ] Build/test commands are exact and verified
  • [ ] File paths are correct
  • [ ] Priority order reflects actual importance
  • [ ] Success criteria are measurable
  • [ ] Starting instructions are specific
  • [ ] No references to "see other document" in CONTINUATION_PROMPT
  • [ ] Handoff directory is NOT staged for git commit

Organizing Handoffs

Recommended directory structure:

ai-assisted/
├── YYYYMMDD/
│   └── HHMM/
│       ├── CONTINUATION_PROMPT.md   # Mandatory
│       ├── AGENT_PLAN.md            # Mandatory
│       └── NOTES.md                 # Optional
